# Registro de decisões de arquitetura (ADRs)

Cada arquivo registra **uma** decisão importante: o contexto, o que foi decidido e as
consequências. Assim, daqui a dez anos, alguém consegue entender *por que* o código é assim.

Para registrar uma nova, copie `0000-modelo.md`, use o próximo número e abra um PR.
Decisões não são apagadas: se mudar de ideia, crie uma nova ADR que substitui a antiga.
